# joholife

魚住惇が運営している高校教科「情報Ⅰ・Ⅱ」の学習支援サイトです。

## 機能

- **問題演習システム**: 各単元の理解度を確認できる問題演習
- **学習ツール**: 2進数変換、16進数変換、画像デジタル化シミュレーターなど
- **論理回路シミュレーター**: 論理回路の動作を視覚的に確認
- **修了証発行**: 100%正答率で修了証を発行

## 対象・目的

- **対象**: 高校生（主に「情報Ⅰ」、一部「情報Ⅱ」）と、情報科の授業を担当する先生
- **目的**: 情報Ⅰ・Ⅱの内容を、シミュレーターや問題演習で手を動かしながら理解すること
- **主な利用場面**: 授業中の演習・教員による投影、家庭での予習・復習
- **作成者**: 魚住惇（連絡先は末尾の「連絡先」を参照。不具合の報告もこちらへどうぞ）
- **最終更新**: 2026年11月（細かな更新履歴はこのリポジトリのコミット履歴をご覧ください）

## データの取り扱い

### データ取扱い区分

ギジュツドットコム「[教育用アプリの公開・授業利用ガイドライン](https://gijyutu.com/main/app_guide)」の区分に沿って整理しています。

| 区分 | 該当する機能 |
|---|---|
| **B**（端末内で扱う） | サイト全体。氏名などの入力や作業内容は、すべてブラウザの中（localStorage）だけで扱い、作成者のサーバーには送信・保存しません |
| **C**（外部通信あり／入力内容は送らない） | 問題演習・鍵交換シミュレーターの修了証発行 |
| **C**（外部通信あり／入力内容を送る） | WHOIS検索 |

このサイトはアクセス解析（Google Analytics など）を使っていません。また、ログイン機能はありません。

### 外部との通信

| 通信先 | 使う機能 | 送られる情報 | 目的 |
|---|---|---|---|
| api.ipify.org（つながらないときは httpbin.org） | 修了証の発行 | 通信に伴うIPアドレスのみ（氏名や回答は送りません） | 修了証に「アクセス元」を印字し、なりすましを防ぐため |
| api.allorigins.win、corsproxy.io など | WHOIS検索 | 入力したドメイン名 | ブラウザから直接取得できないWHOIS／RDAP情報を中継してもらうため |
| chatgpt.com | AIプロンプト集の「ChatGPTで開く」ボタン | ボタンを押したプロンプトの文面（押したときだけ） | プロンプトをChatGPTに入力した状態で開くため |
| fonts.googleapis.com、cdnjs.cloudflare.com、cdn.jsdelivr.net | ページ表示・Python実行環境など | 通常のファイル読み込みのみ | フォントやライブラリ（CodeMirror、Pyodideなど）を配信してもらうため |

サイト本体は GitHub Pages で配信しています。アクセスに伴う技術的なログ（IPアドレスなど）の扱いは、GitHub のプライバシーに関する方針に従います。作成者はこのログを取得・閲覧していません。

### 修了証に印字される情報

修了証には、なりすまし防止のため次の情報が印字されます。修了証は画像としてダウンロードされるだけで、サイトには送信・保存されません。

- 入力した氏名、発行日時
- アクセス元のIPアドレス
- ブラウザ・OSの種類、画面サイズ
- 端末識別コード（ブラウザの描画の特徴などから作る短い符号です。同じ端末なら同じコードになり、端末の中だけで作られます）

### 端末に保存されるデータと消し方

次のデータを、ブラウザのlocalStorageに保存しています。

- 修了証用の氏名（`quizStudentName`）、端末識別コード（`joholife_device_id` など）
- エディタやPythonプレイグラウンドの表示設定・書きかけのコード（`programmingEditor*`、`pythonPlayground*`、`editorContent` など）
- Linuxターミナルの状態（`joholife:linux-terminal:v1:` で始まるもの）

消したいときは、ブラウザの設定から「joho.jun3010.me」のサイトデータ（Cookieとサイトデータ）を削除してください。学校の端末を共用している場合は、使い終わったあとに削除することをおすすめします。

## 利用上の注意

- このサイトは教育目的で作成・公開しているものです。誤りや不適切な表現を含む場合があります。気づいたことがあれば連絡先までお知らせください。
- AIプロンプト集などで生成AIを使う場合、生成される内容は不正確なことがあります。教科書や資料、信頼できる情報源、先生の説明と照らし合わせてください。
- 個人を特定できる情報（氏名、生年月日、学校名、住所、連絡先、写真、成績など）は、先生の指示がある場合を除いて、外部のサービスに入力・送信しないでください。
- 授業で使う場合は、各学校や教育委員会の情報セキュリティに関する規程も確認してください。

## ローカル環境での実行

### 必要な環境

- Node.js 18以上
- npm

### セットアップ

1. リポジトリをクローン
```bash
git clone https://github.com/jun3010me/joholife.git
cd joholife
```

2. 依存関係をインストール
```bash
npm install
```

3. 開発サーバーを起動
```bash
npm run dev
```

4. ブラウザで http://localhost:4321 を開く

### その他のコマンド

```bash
# 本番用ビルド
npm run build

# ビルド結果をプレビュー
npm run preview
```

## 問題演習システム

### 新しい問題セットの追加

1. `public/questions/[unit_name]/` ディレクトリを作成
2. `questions.yaml` ファイルを作成（既存の問題ファイルを参考）
3. `public/questions/index.yaml` の `questionSets` に単元名を追加

### 問題ファイルの構造

```yaml
id: unit_name
title: 単元名
description: 単元の説明
icon: 📝
difficulty: easy|medium|hard
estimatedTime: 数値（分）
category: カテゴリ名
tags:
  - タグ1
  - タグ2
questions:
  - id: q1
    type: single-choice|multiple-choice|true-false
    title: 問題のタイトル
    description: 問題文
    options:
      - id: a
        text: 選択肢のテキスト
        isCorrect: true|false
        explanation: 解説
    explanation: 問題全体の解説
    difficulty: easy|medium|hard
    tags:
      - 問題固有のタグ
    points: ポイント数
    hint: ヒント（オプション）
```
